Honest car advice scoped to a dealer’s lot.

DriveQuest is a conversational advisor with quest-style intake, a hexagonal comparison radar, EV vs gas break-even, and multi-tenant dealer group embeds (optional rooftop location). This Pages site is a static slice — the full FastAPI + LangChain app runs locally from the repo.

Try static shopper demo Read POC docs View on GitHub

Shopper quest

Budget → body → priorities → new/used → hex compare → best match. Commission-free persona.

Dealer groups

Shared inventory + branding; optional location filter for a single storefront embed.

Lot ingest

Excel/CSV upload or comma-delimited paste; bad rows flagged. Live JSON drives recommendations.

Run the full app (not on Pages)

GitHub Pages is static — no long-lived FastAPI here. Locally:

git clone https://github.com/arthursetiawan/car_recommender.git
cd car_recommender
pip install -r requirements.txt
uvicorn backend.app:app --port 8000
# open http://localhost:8000/  ·  /embed/northstar-motors

Demo advisor works without OPENAI_API_KEY. Sample groups: northstar-motors (downtown / westside), lakeside-ev (harbor / lakefront).
