Overview

What DriveQuest is

An embeddable, honest car advisor: quest intake, hex radar, EV ROI, inventory scoped to a dealer group (optional rooftop location).

In scope (POC)

  • FastAPI + static UI; LangChain when keyed, demo advisor otherwise
  • Multi-tenant groups + locations; Excel/CSV/paste ingest
  • Embed via widget.js?group=&location= or iframe
  • Sample tenants: Northstar Motors, Lakeside EV & Hybrid

Out of scope

  • DMS sync, real auth/RBAC, CRM/leads, production hosting on Pages
  • This GitHub Pages site is static — run uvicorn for the full plugin
