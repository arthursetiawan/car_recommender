Runbook

Run the full POC locally

git clone https://github.com/arthursetiawan/car_recommender.git
cd car_recommender
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn backend.app:app --host 0.0.0.0 --port 8000

Open /, /embed/northstar-motors, /embed/northstar-motors/downtown, /static/admin.html?group=northstar-motors. No OpenAI key → demo advisor. Optional: export OPENAI_API_KEY=…
