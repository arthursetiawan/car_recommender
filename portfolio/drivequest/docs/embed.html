Embed

Install on a dealer site

Primary tenant is the dealer group (group=). Optional location scopes inventory to one rooftop. Full install reference in the repo embed-install.md.

GH Pages vs API host

GoalURLWidget?
Recruiter / shopper demo (static) demo.html No — sample lots in-browser
Live embed on dealer website Your FastAPI YOUR_HOST Yes — script or iframe below

Pages does not run /widget.js or chat APIs. Dealer-Counter (fee audit) is a separate repo — not part of this embed.

One-line script (recommended)

<script src="https://YOUR_HOST/widget.js?group=northstar-motors" async></script>

<script src="https://YOUR_HOST/widget.js?group=northstar-motors&location=downtown" async></script>

dealer= aliases group=. Optional &height=900 (default 820).

Iframe

<iframe
  src="https://YOUR_HOST/embed/northstar-motors"
  style="width:100%;max-width:1120px;height:820px;border:0;border-radius:16px"
  title="DriveQuest"
  loading="lazy"></iframe>

Sample tenants

  • northstar-motors → downtown, westside
  • lakeside-ev → harbor, lakefront

Verify

  1. Parent page shows the iframe; greeting names group/location + stock count.
  2. Quest chips only surface cars from that tenant.
  3. After ingest in admin, refresh — prices/VINs match latest inventory.
  4. No backend? Use the static shopper demo and switch lots in the header.
