Group vs location

Primary tenant is the dealer group. Optional location scopes inventory for a storefront site.

Install (full app host)

<script src="https://YOUR_HOST/widget.js?group=northstar-motors" async></script>
<script src="https://YOUR_HOST/widget.js?group=northstar-motors&location=downtown" async></script>

dealer= aliases group=. Pages cannot host this widget’s API — point YOUR_HOST at a running FastAPI deploy, or use the static demo here.

Sample IDs

  • northstar-motors → downtown, westside
  • lakeside-ev → harbor, lakefront
